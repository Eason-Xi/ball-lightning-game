# 代号：宏电子（Project: Macro-Electron）

> 基于刘慈欣《球状闪电》硬科幻设定打造的 2.5D 俯视角物理战术解谜游戏（完整四幕 12 关战役 + 619 自由实验室）。  
> **在线游玩**：https://eason-xi.github.io/ball-lightning-game/  
> **完整设计文档**：[PRD.md](./PRD.md)

## 核心物理机制

1. **非线性电磁导引与导电壁贴壁滑行**
   - 利用超导磁偏转器、高压引雷针（向心吸附 + 38% 过载续能）与银青色**导电金属导流壁（贴壁切向滑行）**构筑电磁轨迹。
2. **四元物质频谱与选择性毁灭（`α / β / δ / γ`）**
   - 场景单位由多材质层组合构成（如 `导弹车 = δ 金属装甲 + α 火控芯片 + β 弹药舱`）。
   - 球状闪电仅气化同频段物质、对其余物质无害穿透；支持逆向运用 `β` 链式次生殉爆与最高管制 `γ` 碳基频段精确打击。
3. **观察者效应、光学遮蔽幕与量子坍缩**
   - **玩家蓝图视觉 ≠ 物理观测者**：仅场景内的物理光锥构成“观测”（混凝土挡光，防弹玻璃透光）。
   - 球状闪电进入无观测盲区即退化为**量子概率云**并穿透实体墙体扩散；可用**光学遮蔽幕**亲手切出敌灯阴影、用 `α` 烧毁敌方监控探头制造盲区、或移动**便携观测信标**透过玻璃精准定向坍缩。
4. **双球宏聚变与量子幽灵干涉**
   - **宏聚变（Macro-Fusion）**：两颗活跃宏电子在极近距离迎面耦合时，爆发半径 `250px` 无视一切混凝土墙体的双色共振脉冲。
   - **量子蓝玫瑰（林云的量子态）**：仅在无观测绝对黑暗中盛开显化，于终局关中以量子干涉压制不可摧毁的敌方强光探头。

## 快捷操作

- `F` / `Enter`：激发宏电子
- `1` `2` `3` `4`：切换谐振频段（`α` / `β` / `δ` / `γ`）
- `O`（或单击场景内绿色信标）：开关己方观测源
- `Space`：实时演算 ↔ 战术时停推演
- `Tab`：切换材质蓝图与爆炸半径视图
- `R`：重置当前实验
- 拖拽发射器瞄准；拖拽偏转器 / 遮蔽幕 / 便携信标外侧圆点或滚轮旋转角度；右键回收已部署装置
