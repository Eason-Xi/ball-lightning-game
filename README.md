# 代号：宏电子（Project: Macro-Electron）

> 基于刘慈欣《球状闪电》硬科幻设定打造的 2.5D 俯视角物理战术解谜游戏 Demo。  
> **在线试玩**：https://eason-xi.github.io/ball-lightning-game/  
> **完整设计文档**：[PRD.md](./PRD.md)

## 核心物理机制

1. **四元物质频谱与选择性毁灭（`α / β / δ / γ`）**
   - 场景中的设施、载具与单位由多种材质层组合构成（如 `导弹车 = δ 金属装甲 + α 火控芯片 + β 弹药舱`）。
   - 球状闪电只气化与其谐振频段匹配的物质层，对其余物质无害穿透；利用这一规则可在不引爆油桶、不伤及人质与黑匣子的前提下完成外科手术式打击。
2. **观察者效应与量子概率云坍缩**
   - **玩家蓝图视觉 ≠ 物理观测者**：只有场景中的物理观测源（敌方巡逻探照灯、监控灯、主动观测信标）构成“观测”。
   - 处于观测光锥内时，球状闪电保持**经典粒子态**，受墙体阻挡；进入完全无观测盲区时，立即退化为**量子概率云**并穿透混凝土实体墙体扩散，待玩家开启信标透过防弹玻璃照亮目标的瞬间，波函数定向内爆坍缩。
3. **非线性的电磁场导引与战术时停**
   - 通过超导磁偏转器、高压引雷针（向心吸附 + 38% 过载续能）控制轨道，随时按 `Space` 进入时停推演模式观察前瞻轨迹与概率幅遥测。

## 快捷操作

- `F` / `Enter`：激发宏电子
- `1` `2` `3` `4`：切换谐振频段（`α` / `β` / `δ` / `γ`）
- `O`（或点击场景内绿色信标）：开关己方主动观测源
- `Space`：实时演算 ↔ 战术时停推演
- `Tab`：切换蓝图材质与爆炸半径视图
- `R`：一键重置当前实验
- 鼠标拖拽发射器可调瞄准角；拖拽磁偏转器外侧圆点或滚轮可调偏转方向；右键回收已部署装置

## 本地运行与测试

```bash
# 安装依赖
npm install

# 启动本地开发服务器
npm run dev

# 运行全 3 关物理模拟自动化通关测试
npm test

# TypeScript 类型检查与生产打包
npm run build
```

## 技术架构

- **模拟内核 (`src/sim/`)**：纯 TypeScript 固定步长 (`dt = 1/60s`) 确定性物理与量子扩散推演引擎，零 DOM 耦合，支持自动化测试。
- **视听表现 (`src/render/`)**：高分屏 Canvas 2D 冷峻军工示波器蓝图渲染器 + Web Audio API 实时程序化声景合成器（零外部音频素材依赖）。
